# StreetSpring open data examples

Examples and documentation for StreetSpring datasets on the [Registry of Open Data on AWS](https://registry.opendata.aws/).

| Dataset | Documentation | Tutorial |
|---|---|---|
| StreetSpring Business Survivability Datasets | [DOCUMENTATION.md](streetspring-survivability/DOCUMENTATION.md) | [Get To Know A Dataset](streetspring-survivability/get-to-know-a-dataset.ipynb) |

The data is public and needs no AWS account: `aws s3 ls --no-sign-request s3://streetspring-seo/open-data/`
